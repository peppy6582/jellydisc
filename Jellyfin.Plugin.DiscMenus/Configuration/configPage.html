Directory scanned (recursively) for "*.menu.json" / "*.binding.json" pairs. Empty uses a "menus" folder under the plugin's data folder.

Menu Files

Every "*.menu.json" in the menus directory and how it was linked to your library. A menu is matched to a title automatically by its TMDB / IMDB / TVDB ids (never by file name), and its extras are matched by type and duration. A "*.binding.json" written by hand next to a menu always takes priority ("manual"). The plugin keeps the bindings it creates itself in its own data folder ("auto"). The library is re-checked when files or the library change; "Scan now" forces it.

Bound Menus

Every "*.binding.json" found under the menus directory, with its paired menu. "Auto-Match" runs the duration matcher and writes results back to the binding file; it never touches bindings already set to Manual or Ignored. "Details" lists every extra key so you can link, ignore, or reset one by hand.
